# Customer Profile — Procurement（目标客户画像：采购合规方向）

> Phase: Gate 5 准备
> 方向: **Procurement（采购合规）**——与 V3 PRD 决策（commit `96dd20d` 2026-09-20）+ ECE v0 Procurement Pack 一致
> 关系: **与 `customer-profile.md`（GRC 方向）并列；Gate 5 阶段按场景选其一**

## 1. ICP（Ideal Customer Profile）

| 维度 | 标准 | 备注 |
|---|---|---|
| 规模 | 200–**3000** 人 | 大到有完整采购部 + 招采合规诉求；小到无独立 ERP / eProc 平台。**>3000 人为超大客段**，需个案评估（见 interview-001 surprise #7：50 亿元/年的快销品客户实际超出原 ICP 上限） |
| 行业 | 制造业 / 工程 / **快销品** / IT 服务 / 国资控股 | 制造业比价痛、国资控股审计严、IT 服务采购杂；**快销品高频采购 + 多 SKU**（见 interview-001 surprise #8） |
| 采购金额量级 | 年采购额 ≥ 5000 万元 | 100 万阈值以上的 PR 才够痛 |
| 采购频次 | 月度 PR 数 ≥ 30（**快销品段 ≥500**） | 频次 = 重复劳动痛感；快销品 50 亿/年 ≈ 5000 PR/年（见 interview-001 surprise #7） |
| 采购政策成熟度 | 已有成文采购政策（含阈值 / 比价 / 审批链）+ **未被严格执行** | "有政策没执行"是 ECE 切入的最佳状态 |
| 已 eProc 化 | 否 / 半 eProc（手工 + Excel/邮件） | 完全 eProc 的（如 SAP SRM）切不动；**OA portal 不算完整 eProc**——只承载"提交 + 审批"，过程数据不在系统里（见 interview-001 B6） |
| 审计/合规诉求 | 内审 + 外部审计（年/季） | 审计 = 付费动力 |
| **双线采购结构** | 生产性 + 非生产性两条独立流程 | 见 interview-001 A1：每条线多级审批（部门→经理→VP→总裁） |
| **本地部署接受度** | 必填；公有云/SaaS 路径通常被否（除非常早期阶段） | 见 interview-001 §3 POC 约束 |

## 2. Persona 优先级

| Persona | 角色 | 访谈价值 | 在创始人网络的可得性 |
|---|---|---|---|
| **P1 采购总监 / 采购合规经理** | 核心用户 | 痛点细节、采购政策执行漏洞、审批链断点 | ★★★★★ 直接（朋友公司多有采购岗） |
| P1b **快销品采购经理**（子 Persona） | 高频采购用户 | 快销品 SKU 多 + 供应商多 + 月度频次高 | ★★★★° 部分可达 |
| **P2 IT 负责人**（**原 P2 = CFO，校准自 interview-001 E14**） | 买家 + 主导实施 | 系统选型、实施、付款主导；ECE 切 IT 部门预算 | ★★★★° 可达 |
| **P3 内审负责人** | 潜在买家 + 第二用例（C1 合规审计） | 审计场景、跨部门证据归集 | ★★★★° 可达 |
| **P4 采购员 / 采购专员** | 一线用户 | 单 PR 流程、跑腿时长、与采购总监的沟通成本 | ★★★★★ 直接 |
| **P5 IT 运维负责人** | 控制责任人 | eProc 接入可能性、数据可得性 | ★★★☆° 部分可达 |
| **P6 被影响部门代表（**新增自 interview-001 D11**）** | 变革阻力源 | "会受到很多人的抵制（消极，不配合）"——ECE 切入时需正面管理 | ★★★☆° 部分可达 |

## 3. 访谈对象来源（Customer Access 落地）

1. 创始人现有网络：制造业 / 工程类公司采购岗朋友（优先 3 位）
2. 朋友公司引荐：要求**正在准备或刚经历** ISO 20400 / 内审 / 外部审计
3. 行业社群：采购协会、内审协会活动、CIO 社群
4. 招聘信号：正在招"采购合规经理" / "采购总监" JD → 说明采购合规扩张期
5. 目标配额：**P1×3、P2×1、P4×1 = 5 场**（顺带验证 P3 内审是否构成第二用例）

## 4. 排除标准（不约）

- 已深度使用 SAP SRM / Oracle Procurement / 用友 YonBIP 等成熟 eProc（切不动；可记录为差异化输入）
- 完全无成文采购政策（采购金额 < 100 万为主，痛感不足）
- 采购流程全外包给第三方代采（ECE 切不到内部 PR 流程）
- 无法安排 30 分钟有效对话的联系人
