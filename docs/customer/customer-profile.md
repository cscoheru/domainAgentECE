# Customer Profile（目标客户画像）

> Phase: Gate 5 准备
> 访谈目标：2–4 周内完成 5 场有效访谈（创始人网络直达）

## 1. ICP（Ideal Customer Profile）

| 维度 | 标准 | 备注 |
|---|---|---|
| 规模 | 200–2000 人 | 大到有审计负担，小到无专职大团队 |
| 合规状态 | 已通过 SOC2/ISO 初次认证，进入**续证/常态化**阶段 | 首证公司通常买 Vanta 类工具 |
| 已有 Glean/企业搜索 | 加分项（POC 路径短） | 非必需（REST 直连路径） |
| GRC 团队 | 1–3 人小团队 | 人越少痛感越强 |
| 审计频率 | 至少年度 Type II + 内审 2–4 次/年 | 频率=付费动力 |

## 2. Persona 优先级

| Persona | 角色 | 访谈价值 | 在创始人网络的可得性 |
|---|---|---|---|
| **P1 GRC/合规经理** | 核心用户 | 痛点细节、工作流、数据位置 | ★★★★★ 直接 |
| **P2 内审负责人** | 次级用户+潜在买家 | 内审场景（第二用例）、预算 | ★★★★★ 直接 |
| **P3 CISO/安全总监** | 买家 | 预算、供应商决策标准、安全边界 | ★★★★° 可达 |
| P4 采购经理（C3 探询） | 相邻用例 | 评标痛点探询（每场访谈带 2 问） | ★★★★★ 直接 |
| P5 IT 运维负责人 | 控制责任人 | 被派工方体验、配合度 | ★★★☆° 部分可达 |

## 3. 访谈对象来源（Customer Access 落地）

1. 创始人现有网络：安全合规/审计/采购 function 同事与前同事（优先 3 位）
2. 朋友公司内审/合规岗引荐（要求：正在准备或刚经历 SOC2/ISO 续证）
3. 行业社群：安全合规/GRC 社区、内审协会活动、CISO 社群
4. 招聘信号：正在招 GRC/合规专员的JD → 说明在扩张审计负担
5. 目标配额：P1×3、P2×1、P4×1（顺带 C3 验证）= 5 场

## 4. 排除标准（不约）

- 未做过任何审计的企业（无痛感）
- 已深度使用 Vanta/Drata 且满意（先记录其不满点，作为差异化输入）
- 无法安排 30 分钟有效对话的联系人
