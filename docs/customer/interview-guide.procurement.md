# Interview Guide — Procurement（采购合规方向访谈指南）

> Phase: Gate 5
> 方向: **Procurement**（采购合规）——与 V3 PRD 决策 + ECE v0 Procurement Pack 一致
> 关系: **与 `interview-guide.md`（GRC 方向）并列；Gate 5 阶段按场景选其一**
> 形式: 30–45 分钟视频/面谈；前 15 分钟 Demo（[demo-script.md](./demo-script.md)），后 20–30 分钟本指南
> 原则: **不是卖软件，是验证痛点、数据可得性、POC 意愿**（CLAUDE.md Gate 5）

## 0. 开场声明（必读）

> "今天主要想了解你们**采购合规 / 100 万阈值以上 PR**的真实工作方式，Demo 只是引子。我们不会推销，您的任何'这不对/我们不是这样'的反馈对我最有价值。"

记录元数据：日期 / 受访人角色 / 公司规模 / 行业 / 采购年金额量级 / 录音许可。

## 1. 核心问题（15 问，按 V0 Spike demo 三件证据设计）

### 现状（A）

1. 你们现在 100 万+ 的采购申请（PR）流程是什么？谁发起、谁审、谁批？
2. 多久一次（年度 / 季度 / 月度）？单 PR 平均跑多久？
3. 单 PR 全流程需要多少人 × 多少小时？
4. 最大痛点是哪一步？（找政策对照 / 比价收集 / 审批催签 / 付款合规 / 审计应对）
5. 哪一步最需要**专业判断**（而不是体力活）？

### 数据与系统（B）

6. 采购 PR / 比价记录 / 合同 / 付款凭证存在哪些系统？（Excel / 邮件 / ERP / OA / 本地）
7. 这些系统之间权限是怎么管的？采购员能不能看到别部门 PR？财务能不能看到别部门比价底价？
8. 有没有统一知识平台（Glean / 飞书 / 钉钉 / Confluence）？采购政策放哪？

### 判断标准（C）

9. 怎么判断一份 PR "合规"？（有无内部 checklist / 经验规则 / 系统校验）
10. 历史上有没有"被审计师指出 PR 不合规 / 比价不足"的经历？损失是什么？

### AI 接受度与价值（D）

11. 如果 AI 能完成**采购政策对照 + 比价完整性检查**的 70–80%，价值多大？（时间/合规风险量化）
12. 什么情况下你们**愿意让 AI 真正执行**（自动派单 / 生成草稿合同 / 自动归档）？
13. 什么情况下**必须人工审批**？（金额阈值？特定供应商？）

### 商业路径（E）

14. 这类工具谁是决策人？预算从哪里出（采购 / 财务 / 内审 / IT）？
15. 如果 POC 成功，什么条件下愿意付费？（年订阅 / 按 PR 量 / 按合规检查次数）

## 2. C3 顺带探询（采购视角，每场带 2 问，仅 P4 深问）

- 你们采购评标现在怎么对比 5–10 家供应商的应答？
- 如果 AI 自动生成"逐项对照矩阵 + 澄清问题清单"，有用吗？

## 3. 收尾与承诺（必做）

> "如果这个系统接入你们真实采购数据做一次小范围验证（脱敏快照即可），您愿意参加吗？下一步我约您和 [采购总监 / CFO] 同事 30 分钟可以吗？"

记录：Next Step / 时间 / 引荐人。

## 5. 访谈纪律

- 不引导性提问（❌"你们是不是觉得比价收集很烦？" ✅"哪一步最耗时？"）
- 每场后 24 小时内写完记录
- 第 3 场后做一次假设校准会（对照 `validation-metrics.procurement.md`）
- **不与 GRC 访谈串味**：每场前确认 ICP 是 Procurement 而非 GRC

## 6. 与 GRC 访谈指南的差异

| 维度 | GRC | Procurement |
|---|---|---|
| 核心痛点 | 审计证据归集 | PR 合规检查 + 比价完整性 |
| 决策节奏 | 季度/年度（续证） | 月度/单 PR（实时） |
| 付费动力来源 | 续证失败风险 | 单 PR 违规罚款 + 审计整改 |
| AI 替代边界 | 证据收集可以、判断不行 | 比价检查可以、政策解释不行 |
