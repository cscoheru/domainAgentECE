## 2. 排名规则与最终 Top 3

**PRD #17 明文规则**："如果市场很大，但无法获得客户访谈机会，应降低优先级。"
创始人约束：2–4 周内约到 5 场访谈是硬性 Gate（用户核心目标：MVP→访谈→POC）。

- C2（RFP）：CA=2、FF=2 → 无法从现有网络获得访谈 → **降级为战略备选**（分数保留诚实记录）
- C7（咨询）、C5（支持）、C6（QBR）：同理 CA=2 → 降级
- C1（审计证据）：CA=5、FF=4、WTP=5、IP=5 → **学习速度最高**

**最终 Top 3**：

```text
🥇 C1 审计证据智能（EvidenceIQ）   → 推荐 MVP（详见 ADR-002）
🥈 C3 采购评标/供应商智能           → 第二验证对象（访谈中顺带探询）
🥉 C2 RFP 应答智能                 → 战略备选（获得售前渠道后启动）
Watchlist: C4 项目健康预警、C8 事故复盘
```
