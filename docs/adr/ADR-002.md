# ADR-002: MVP 选择 Audit Evidence Intelligence（EvidenceIQ）而非加权分更高的 RFP 应答

- Status: Accepted
- Date: 2026-09-03
- Deciders: 产品负责人（创始人）+ AI 架构师（Cline）

## Context

1. 候选评分中 RFP 应答智能原始加权分最高（4.25 vs 审计证据 4.20）。
2. 但创始人确认（2026-09-03）：人脉网络集中在 **HR、采购、产品研发、安全合规、财务审计** function 部门——**没有售前/销售网络**。
3. 项目最高目标是：MVP → 2–4 周内 5 场真实客户访谈 → POC（CLAUDE.md 第 0/1 节；PRD #17）。
4. PRD #17 明文规则："如果市场很大，但无法获得客户访谈机会，应降低优先级。"

## Decision

第一 MVP 选择 **C1 审计证据智能（EvidenceIQ）**；RFP 应答（C2）降级为战略备选。

决策依据（按重要性排序）：

1. **Customer Access 5/5 vs 2/5**：GRC/内审/采购人群在创始人网络内直接可达——学习速度（Customer Learning Velocity）最大化，这是 PRD #18 的第一选择标准。
2. **WTP 5/5 + 预算刚性**："过不了审计"是可量化商业风险，合规预算独立于经济周期。
3. **Domain IP 5/5**：控制-证据本体 + 四类推理 + 回归评估集，三层可防御资产；Glean observability 不含业务正确性（C22），平台向上侵蚀（C21）也难以覆盖审计专业判断。
4. **竞争空白更清晰**：RFP 赛道有 Responsive/Loopio/AutogenAI 成熟玩家；审计证据的"人工证据类控制 + 企业上下文推理 + 内审多框架"是 Vanta/Drata（云配置自动测试、SMB）未覆盖的空白。
5. **C9（TPRM 问卷）天然是第二曲线**：同一本体家族，验证后可扩。

## Consequences

- ✅ 2–4 周访谈路径明确（customer-profile.md §3 已列配额与来源）
- ✅ 创始人领域知识（审计/合规）直接转化为本体质量——FF=4
- ⚠️ 放弃 RFP 的更大 TAM 与 5/5 演示效果——记录为战略备选，获得售前渠道（合作/招聘/社区）后重评
- ⚠️ 审计客户数据敏感——POC 优先脱敏快照或客户侧部署路径（portability.md）
- ⚠️ 若 5 场访谈均 Severity<3（validation-metrics.md §5），按停止条件切换 C3 采购评标（同为 CA=5 候选）

## Alternatives Considered

| 方案 | 否决理由 |
|---|---|
| C2 RFP 应答（分数最高） | CA=2/FF=2，2–4 周无法获得访谈 → 违反 PRD #17 与项目最高目标 |
| C3 采购评标（同为 CA=5） | Pain 3 vs C1 的 4；评标频率低于审计续证+内审；且 C1 的本体/推理资产更深 —— 作为第二验证对象保留 |
| C4 项目健康预警 | CA=3（间接可达），作为 Watchlist |
