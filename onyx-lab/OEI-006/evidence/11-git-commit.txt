feat(OEI-006): merge content-engine recall into the Consulting Library

Adds a second source to GET /api/v1/consulting/library alongside the 36-object
static seed catalogue: engine-recalled documents from indexed real files, with
source labels, detail-drawer reuse, and explicit degradation / empty states.

The static side is untouched — engine results travel in new fields only
(`engine_items` / `engine_status`), and the router computes the static response
first and merges with `model_copy(update=...)`, which structurally guarantees
existing static fields stay byte-identical for current consumers. `engine_status`
is a four-state policy: ok / unavailable / disabled / skipped, deliberately
fail-closed so the mock adapter's canned documents are never presented as the
customer's own uploads.

Also fixes a child-process leak in
tests/integration/test_cut_045_local_origin_smoke.py: TimeoutError is an OSError
but not a urllib.error.URLError, so it escaped the readiness helper before the
try/finally and left uvicorn running. Both children are now reclaimed
unconditionally, and a missing deployment stack is an explicit skip instead of a
failure.
