# 咨询方法论：问题树、假设驱动与 MECE 的实战组合

> **标注**：本方法论为 **Demo Case** 演示文档，整理自多个内部培训材料与项目复盘，用于评估 Onyx CE 在方法论类内容上的检索召回与引用可追溯性。

## 1. 为什么这三件事必须绑在一起用

咨询行业最容易出现的失败模式，是"问题没拆清楚就急着给答案"或者"方案做了 12 个但互相重叠"。**问题树**负责把模糊的业务问题拆成可分析、可指派的子问题；**假设驱动**强迫团队在动手验证之前先声明"我以为答案是什么"；**MECE（Mutually Exclusive, Collectively Exhaustive）**则保证最终交付的方案彼此独立、合起来覆盖全部情形。三者不是可选配件，而是同一条流水线上的三道工序。

## 2. 问题树（Issue Tree）

### 2.1 定义

问题树是一种自顶向下的演绎结构，根节点是客户提出的原始问题，叶节点是可直接指派给某一数据源或某一分析师回答的子问题。常见结构是 3 层：

- **L1 业务问题**：用客户原话表述，不擅自加工；
- **L2 拆解维度**：通常是 4–6 个互不重叠的拆解轴（如收入=价格×数量、价格=产品组合×定价策略）；
- **L3 可分析子问题**：每个 L2 节点下挂 2–4 个 L3 子问题，每个 L3 必须能在 1–3 天内回答。

### 2.2 常见错误

- 在 L1 就替客户改写问题，丢失原始语境；
- L2 拆解维度重叠（例如同时用"区域"和"渠道"，但二者存在交叉）；
- L3 子问题颗粒度过粗，需要 2 周才能回答，违背"可执行"。

### 2.3 输出模板

```
【L1 原始问题】 <客户原话>
├──【L2.1 维度A】
│   ├──【L3.1.a】<子问题>｜数据源：<表/系统>｜负责人：<姓名>｜预计工时：<人天>
│   └──【L3.1.b】...
├──【L2.2 维度B】...
```

## 3. 假设驱动（Hypothesis-Driven）

### 3.1 假设的写法

一条合格的假设必须包含四个要素：**动作**、**对象**、**预期数值变化**、**时间窗口**。例如"通过整合前 20 大供应商，集中度提升 10 个百分点，可在 12 个月内降低采购成本 1.4%"。

### 3.2 验证优先级

用"业务影响 × 验证可行性"二维矩阵排验证顺序：

- 第一梯队：高影响 + 易验证（先做）；
- 第二梯队：高影响 + 难验证（拆子假设）；
- 第三梯队：低影响 + 易验证（顺手做）；
- 第四梯队：低影响 + 难验证（不做）。

### 3.3 验证失败的正确姿势

假设被证伪不是失败，是节省时间。**关键纪律**是：证伪必须留下"为什么错"的证据链，而不是简单标"不成立"三个字。这是后续复盘最有价值的资产。

## 4. MECE 的实战守则

### 4.1 排他性（ME）

检验方法：拿出任意两条子项，问"这两件事有没有可能被同一段话同时描述"。如果可以，说明存在交叉，需要进一步切分。最常见的反例是按"区域"和"渠道"同时切客户——线下大客户、线上大客户、线下小客户、线上小客户这种 2×2 才是 ME 的。

### 4.2 穷尽性（CE）

检验方法：把所有子项合起来，能否覆盖原问题的全部情形。如果有遗漏，通常表现在"其他"这一项占比超过 20%，说明分类轴选错了。

### 4.3 常见分类轴

- 按对象（产品、客户、区域、渠道）；
- 按动作（开发、获取、留存、变现）；
- 按时间（短期、中期、长期）；
- 按内外部（内部能力、外部市场）。

不要在同一层级混用多种轴，否则 ME 必然被破坏。

## 5. 三者如何咬合

```
问题树（结构）        →  拆出可分析的子问题
        ↓
假设驱动（节奏）      →  对每个子问题声明假设
        ↓
MECE（输出守则）      →  对最终方案集合做 ME/CE 检验
```

实际项目中三者循环使用：问题树拆完一轮后，用 MECE 检查子问题是否互斥穷尽；若不满足，回到问题树重新切分；方案初稿出来后，再用 MECE 检查最终交付物是否互斥穷尽；若不满足，回到假设驱动的优先级矩阵重新排序。

## 6. 何时不该用

- 客户问题本身极小（"帮我做个 PPT"）：上方法论就是过度工程；
- 客户未授权访问任何数据：假设驱动跑不起来；
- 时间窗口 < 3 天：问题树来不及拆完。

## 7. 小结

问题树、假设驱动、MECE 不是三个工具，而是同一套**思维方式**的三个切面。把这套思维方式内化到团队肌肉记忆，远比单点工具更重要。这也是为什么咨询行业的真正护城河，是方法论的可复用性，而不是某个具体案例的产出物。
